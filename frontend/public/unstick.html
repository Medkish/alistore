AliStore — reset site data

An earlier version of this site's service worker cached every response, including book covers, and reloaded the page whenever it updated. Some browsers are still running it and can be holding a large stale cache that hides the real cover images. This page removes every service worker and every cached response for localhost:4000, then re-registers the corrected worker. It is safe to run more than once.
